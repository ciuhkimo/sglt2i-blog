## 一句話回答

**可以，而且值得。** 關鍵不是「能不能去」，而是「有沒有做對規劃」。先確認透析安排，再訂機票。

---

## 適用對象

病況穩定的維持性血液透析（HD）、腹膜透析（PD）成人病人，以及穩定的腎臟移植病人。

## 先和透析團隊討論再規劃

如果近期有住院、通路問題、體液控制不佳、反覆高血鉀、活動性感染或共病不穩定，請先處理好再出發。

> [!warning] 移植病人特別提醒
> 移植後第一年、近期排斥、感染、CMV 治療中、免疫抑制劑調整中或腎功能不穩者，**應先與移植團隊討論**，必要時延後高風險地區旅行。詳見下方「移植病人旅行專區」。

---

## 核心原則：先透析，再訂票

| 順序 | 做什麼 |
|---|---|
| 1 | 和腎臟科 / 透析室討論，確認「可以旅行」 |
| 2 | **預約目的地透析中心**（HD）或安排藥水寄送（PD） |
| 3 | **拿到目的地中心或供應商書面接收確認**後，才付不可退費的機票和住宿 |

## HD 旅行規劃

### 預約客座透析

| | 國內 | 國外 |
|---|---|---|
| **提前** | 至少 2-4 週（連假 1 個月） | 至少 6-8 週；熱門地區、連假、需 HBV/HCV/HIV 隔離、行動不便者建議 2-3 個月以上 |
| **管道** | 原透析室護理長協助 + TSN 透析院所查詢 | 依目的地分流（見下方說明）|
| **健保** | 正常給付，重大傷病免部分負擔 | 僅符合健保署規定情境可申請自墊核退（見下方〈健保與保險〉）|

**國外管道分流**（依目的地）：

- **Fresenius Holiday Dialysis**：以其網絡與在地服務為主
- **Bookdialysis（[bookdialysis.com](https://bookdialysis.com)）**：公開平台，涵蓋部分國家 / 城市
- **TDQ（台灣腎友媒合）**：服務範圍變動較快，**請查最新公告**（近期曾與 Bookdialysis 合作供病人自助查找海外中心）
- **DaVita**：主要為**美國境內**中心網絡；海外多為協助 DaVita 病人文件流程，**不是全球查找平台**

### 要準備的文件（中英文）

- 病摘 / 透析摘要、近期出院病摘（如住過院）
- 血清學（1-3 個月內）：HBsAg、anti-HBs、anti-HCV、anti-HIV
- 近期生化（4 週內）：CBC、Na、K、Ca、P、albumin、BUN、Cr
- 心電圖、**近期胸部 X 光**
- **3-5 次透析紀錄 / run sheet**（部分目的地中心要求）
- 透析處方：模式、血流速、透析液、抗凝劑、乾體重
- 通路資訊：AVF / AVG / CVC、位置、針號
- 用藥清單(學名為主) + 過敏清單
- 醫師英文放行信
- **付款 / 保險資料**
- 部分中心要求 MRSA / VRE / COVID 等篩檢

### 行程排班原則

- **出發前一天做 HD**——把透析間隔留到飛行那天
- 抵達後儘快安排首次透析
- **任何兩次間隔不超過 2-3 天**——漏透析會堆積鉀和水分
- **跨時區可預留休息時間，但不得因此延長透析間隔**。首次目的地透析日期應依原透析間隔、尿量、水分 / 血鉀控制、航班延誤風險與當地可用班別決定

### 通路保護

- 安檢門和 X 光不會傷瘻管
- 通路那隻手：不量血壓、不打針、不提重物、不壓睡
- 每天摸 thrill——失去震顫**當日立即就醫**（見下方〈旅途緊急狀況〉）
- **CVC 病人**：敷料保持乾燥，**禁泡溫泉、泡澡、海水浴**

## PD 旅行規劃

### 藥水寄送

- **Vantive (Baxter)** 與 **Fresenius** 等供應商有旅遊支援服務，**但是否支援目的地、藥水種類、寄送地址、海關文件、費用與技術支援，需由原 PD 團隊與供應商逐案書面確認**
- **lead time 請以供應商書面回覆為準**：公開資料顯示常需**至少 10 週至 3 個月**，部分地區需 **≥4 個月**。lead time 應從完整處方、訂單與文件送達供應商後起算
- ⚠️ **郵輪、離島、偏遠地區、災害地區或海關限制國家可能無法寄送**；關稅、倉儲、退貨、銷毀、廢棄物處理費可能需病人負擔
- **機器（cycler）、敷料、口罩、藥物要自己帶**

### APD vs CAPD

| | CAPD | APD |
|---|---|---|
| 設備 | 無機器，較單純 | 需攜帶 cycler |
| 白天彈性 | 需 4 次 / 日換液 | 夜間機器做，白天較自由 |
| Backup | — | **需與 PD 團隊事先制定 CAPD backup plan** — 至少備足可因應航班延誤、機器故障、補貨失敗或目的地無技術支援的 CAPD 用量；實際天數依行程、目的地與供應商支援決定 |

### 設備電壓與相容性

> [!warning] 不要假設「只需轉接頭」
> APD cycler 電源規格請以**機身標籤、原廠說明書、PD 護理師 / 供應商書面確認**為準。國際旅行可能需要轉接頭或變壓器；不同國家的機器技術支援、藥水袋、管路與 adapter 相容性可能不同。

- 出國前向 PD 團隊與供應商書面確認該機型、該批次、該目的國的：電壓 / 變壓器需求、技術支援、藥水袋與管路相容性
- 台灣 110V/60Hz；日本 100V；歐洲多 220-240V（僅作背景參考，不取代原廠書面確認）

### 換液環境

密閉房間 + 洗手槽 + 戴口罩 + 洗手 + 不開門窗讓風吹 + 不讓寵物在場

## 移植病人旅行專區

> 本篇 SEO slug 為 `travel-dialysis-transplant`，但前面內容以 HD/PD 為主。移植病人請特別注意以下：

- **時機**：移植後第一年、近期排斥、感染、CMV 治療中、免疫抑制劑調整中或腎功能不穩者，應先與移植團隊討論，必要時延後高風險地區旅行
- **免疫抑制劑（IS）攜帶與用藥**：tacrolimus / cyclosporine、mycophenolate、sirolimus / everolimus、steroid 等須**隨身攜帶、保留原包裝、備足額外天數**；跨時區需預先排好服藥時間與抽 trough 的安排
- **腹瀉 / 嘔吐 / 發燒**：可能改變 IS 濃度（特別是 tacrolimus / cyclosporine），需**盡快聯絡移植團隊**
- **抗生素 / 抗黴菌 / 抗病毒藥物**：可能與 calcineurin / mTOR inhibitors 發生重大交互作用（如 macrolide、azole、rifampin、Paxlovid 等）；**不要自行買藥**
- **疫苗**：活性疫苗通常不適合嚴重免疫抑制者（黃熱病、口服傷寒等需事前評估，必要時改行程或申請 waiver）；COVID、influenza、HBV、HAV、pneumococcal、zoster 等依個別狀況補齊
- **食物 / 飲水安全**：避免生食、生海鮮、未煮沸水、受污染水域

## 藥物與文件（隨身，不要託運）

### 攜帶清單

- [ ] 健保卡、護照
- [ ] 中英文病摘 + 透析處方
- [ ] 用藥清單（學名）+ 過敏清單
- [ ] 足量藥物（旅程 + **至少 7-14 天 buffer**）
- [ ] 疫苗紀錄
- [ ] 緊急聯絡：原透析中心 24h 電話、目的地透析中心、保險服務專線、家屬
- [ ] 「救命卡」/ ICE / 英文 renal travel summary（見下方）
- [ ] 保險文件 + 健保核退申請書空白

### 跨時區用藥

- **降壓藥、利尿劑、糖尿病藥、磷結合劑、鉀結合劑與免疫抑制劑**，不建議自行「補吃」或「一次吃兩次」
- **q12h / q24h 藥物**出發前請與醫師或藥師排好轉換表；抵達後以**當地時間**固定服藥，避免漏藥與重複服藥
- **移植病人** tacrolimus / cyclosporine / sirolimus / everolimus，若跨時區、腹瀉、嘔吐或使用抗生素 / 抗黴菌藥 / Paxlovid，需特別注意 trough level 與交互作用
- **ESA 與 IV iron**：旅行時間短，通常安排在出發前或返國後；長期旅行需由目的地透析中心確認醫囑、藥品、費用與給藥責任

### 藥物跨境攜帶（TFDA / 海關規範）

- **藥物保留原包裝**，攜帶英文處方 / 診斷書與學名清單
- **台灣入境處方藥**：有處方或證明文件者，合理自用量最多 **6 個月**；無證明文件者通常以 **2 個月** 為限
- **針劑**：需醫師處方或證明文件
- **管制藥品**：各國規範不同，**不得任意郵寄或快遞**，出入境前需確認目的國與台灣規定
- **醫療器材與耗材**：跨境攜帶或郵寄涉及個人自用醫材輸入規定；耗材通常以 6 個月用量為原則，超量或非列名項目應事先向 TFDA / 海關確認

### 英文 ICE / Renal Travel Summary（minimum dataset）

英文病摘建議至少包含：

- 姓名、護照英文名、生日、緊急聯絡人、台灣主治醫師與透析室電話
- ESRD / CKD / PD / HD / 腎臟移植狀態
- 最近一次透析日期與時間、平時透析日、dry weight、常見透析前後血壓
- HD access 類型與位置；PD catheter 位置與 PD prescription
- 過敏、抗凝血藥、免疫抑制劑、糖尿病藥、鉀結合劑
- 近期 Hb / K / albumin / Cr 或必要 labs
- 保險公司、保單號碼、海外緊急電話

## 飛行、高山與長途移動

- **長途飛行 / 車程 >4-6 小時**會增加靜脈血栓（DVT）風險：建議定時走動、做小腿運動，必要時選走道座位
  - 高風險病人是否使用壓力襪或抗凝預防，需由醫師評估
  - **不建議自行吃 aspirin 預防血栓**
- **客艙壓力**約等同 6,000-8,000 ft：高度、乾燥與久坐可能加重心肺疾病、貧血、缺氧或水分問題；需要氧氣者需提前向航空公司確認
- **高山旅遊**或快速上升至 **>2,500-3,000 m**：若有嚴重貧血、心衰竭、肺高壓、血壓控制差或近期住院，應先評估
  - **Acetazolamide**：在明顯腎功能不全、電解質異常或代謝性酸中毒者**可能禁忌**，**不宜自行購買使用**

## 飲食水分

- 低鈉低鉀控磷的原則照舊
- **磷結合劑隨餐吃**——包括飛機餐和當地外食
- 機艙乾燥容易渴：用小口、含冰塊、無糖口香糖解渴，**不超過每日水分上限**
- **飲食衛生**：瓶裝水（含刷牙）、避免生食、不用路邊冰塊
- **旅行下痢**對 CKD / 透析 / 移植病人風險較高（脫水、AKI、藥物濃度變化、電解質異常）

## 健保與保險

> [!important] 截至本次查核可見（2026-05-09）；申報前請以**最新版健保署支付標準查詢系統**與您的承保壽險公司條款為準。

### 健保自墊核退

- **健保不會因出國洗腎而中止**：2024/12/23 起取消停復保制度；有戶籍者出國期間**仍須持續加保並繳納保費**
- **可申請核退的情境**：限健保署規定的「**特殊傷病**」「**不可預期的緊急傷病**」「**緊急分娩**」等情境，且須在當地醫事服務機構就醫並經審查；**預先安排的海外客座透析不宜寫成必然可核退**
- **申請期限**：門診或急診治療當日、或出院日起 **6 個月內**申請；若尚未返國，可委託他人辦理
- **申請文件**：申請書、收據正本、費用明細、診斷證明、出入境證明
  - 非中英文文件需中文翻譯
  - 住院需附**出院病歷摘要**
  - **中國大陸地區住院 5 日以上**：收據與診斷書須經**公證及海基會驗證**
- **給付上限**（115 年第 2 季公告）：
  - 門診每次 NT$1,121
  - 急診每次 NT$3,844
  - 住院每日 NT$6,686
  - **血液透析與論病例計酬案件**：依實際接受門診、急診或住院服務項目上限辦理
  - 上限**遠低於海外實際費用**

### 旅平險

- **旅平險主約**多保障**意外傷害**；疾病醫療需看是否另加「**海外突發疾病醫療**」附約
- **規律透析、ESRD/CKD 既有病況、以治療為目的之出國與預定透析費用**，通常**不屬突發疾病承保範圍**（突發疾病一般定義為附約生效前一定期間內未曾診斷或治療、且旅途中需立即就醫的疾病）
- **各保險公司條款不同**：對既往症、法定傳染病、除外責任、回溯期間與理賠文件規定不同；**不宜寫成所有保險商完全一致**
- **投保前**應書面告知腎臟病 / 透析 / 移植狀態，並逐條確認保單條款、除外責任與海外就醫理賠文件

## 旅途中每天做 3 件事

1. **量體重**——超出乾體重 2-3 kg 要警覺
2. **量血壓**——不在通路那隻手
3. **檢查通路 / 出口處**——AVF 摸 thrill；PD 看有無紅腫

## 旅途緊急狀況

### 🔴 立即就醫

- **PD 透析液混濁** ± 腹痛 ± 發燒——保留混濁透析液袋帶到急診
- **AVF/AVG 失去 thrill、腫痛、變冷**——**當日立即聯絡透析中心、血管通路團隊或急診**；不要等到下一次透析才處理
- **通路出血壓 20 分鐘止不住**——持續壓迫 + 叫當地急救
- **氣促、無法平躺、咳粉紅泡沫痰**——急性肺水腫
- **胸痛、心悸、暈厥**
- **肌肉無力、麻木、心律不整**——疑高血鉀
- **發燒 ≥38°C 合併寒顫**——疑通路感染

### 旅行下痢與紅旗

若出現**腹瀉合併**：發燒、血便、持續嘔吐、無法服藥、明顯口渴 / 頭暈 / 低血壓、尿量下降、體重快速下降、PD 透析液混濁，或**移植病人腹瀉超過 24 小時**——應**盡快就醫**或聯絡原醫療團隊。

腹瀉與嘔吐可能造成脫水、低血壓、AKI、鉀離子異常，也可能改變 tacrolimus / cyclosporine 等藥物濃度；**不要自行購買抗生素、NSAIDs 或草藥**。

### 漏透析怎麼辦？

**不可用降鉀劑替代透析。**

- 若漏透析：先避免高鈉、高鉀與額外攝水，並依**原本個別限水、尿量與體重變化**處理；無尿 HD 病人通常需更嚴格控水
- 若合併**腹瀉、嘔吐、發燒、中暑、低血壓或無法服藥**，**不要硬套固定水量**，應立即聯絡透析團隊或就醫
- 立即找當地透析中心或急診安排緊急透析

## 常見迷思

| 迷思 | 事實 |
|---|---|
| 洗腎病人不能旅行 | 穩定腎友規劃得當就能旅行 |
| 出國洗腎健保就停了 | 健保不會中止（2024/12/23 起取消停復保），但海外洗腎**僅限特殊 / 緊急情境**可申請事後核退（有上限），不是預先安排的客座透析必然可核退 |
| PD 藥水隨時可寄到任何國家 | 各供應商有旅遊支援，**但要逐案書面確認**；郵輪、離島、偏遠地區、海關限制國家可能無法寄送 |
| 短程出去漏一次洗腎沒差 | **最危險的迷思**——漏透析會堆積鉀和水分，可致命 |
| 機場安檢會傷瘻管 | 不會，但請安檢避免在瘻管上反覆按壓 |
| 買了旅平險就萬事 OK | 主約多保障意外；疾病需看海外突發疾病附約；規律透析與既有病況通常不在承保範圍 |
| APD 機器只要轉接頭就能用 | 不一定。請與供應商書面確認該機型、該目的國的電壓 / 變壓器 / 技術支援 / 藥水袋相容性 |
| 洗腎病人不能泡溫泉 | CVC 和 PD 導管者避免；成熟瘻管者可在限制下適量 |
